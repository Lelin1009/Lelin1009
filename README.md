# 수석 안내판 제작기

순천세계수석박물관 수석 안내판(1200 × 1800)을 만드는 웹 프로그램입니다.
사진을 올리면 **자동으로 누끼를 따고**, 입력한 이름·산지·규격을 템플릿에 맞춰 배치해 PNG로 저장합니다.

## 앱으로 설치하기

주소: **https://lelin1009.github.io/Lelin1009/**

- **아이폰/아이패드**: Safari로 주소를 열고 → 아래쪽 공유 버튼(네모에 위쪽 화살표) → **홈 화면에 추가** → 추가
- **갤럭시(안드로이드)**: Chrome으로 주소를 열고 → 화면 위 **설치** 버튼 (또는 메뉴 ⋮ → **앱 설치 / 홈 화면에 추가**)
- **PC (Chrome·Edge)**: 주소창 오른쪽 설치 아이콘 또는 화면 위 **설치** 버튼

설치하면 홈 화면 아이콘으로 주소창 없이 전체 화면으로 열립니다.
한 번 사진 누끼까지 해 두면 그다음부터는 **인터넷 없이도** 작동합니다.

## 사용법

1. **사진 선택**: 수석 사진을 고르면 AI가 배경을 지웁니다. 처음 한 번은 AI 모델(약 100MB)을 내려받고, 그다음부터는 브라우저에 저장된 것을 씁니다.
2. **누끼 수정** (필요할 때만): `지우개`로 남은 배경을 지우고, `복원`으로 잘못 잘린 부분을 되살립니다. `확대`한 뒤에는 `이동`으로 화면을 옮기면 됩니다.
3. **글 붙여넣기**: 아래처럼 붙여넣으면 제목·산지·규격이 자동으로 채워지고, 영어·중국어 제목은 자동 번역됩니다.
   ```
   안개낀 첩첩산중
   산지:한국
   규격:380*370*140
   ```
   - 한 줄로 `안개낀 첩첩산중 산지:한국 규격:380x370x140` 처럼 써도 됩니다. `x`, `×`는 `*`로 바뀝니다.
   - `영어: …`, `중국어: …` 줄을 넣으면 번역 대신 그 제목을 씁니다.
   - 번역은 기본이 **무료 번역**(Google)이고, `번역 설정`에서 **Claude AI 번역**(API 키 필요, 더 자연스러움)으로 바꿀 수 있습니다.
4. **확인·수정**: `자동으로 채워진 내용`에서 틀린 곳을 고칩니다. 직접 고친 영어·중국어 칸은 자동 번역이 덮어쓰지 않습니다. 다시 자동으로 받으려면 `다시 번역`을 누르세요.
   - 외국어는 `English / 中文` 한 줄로 들어가고, 길면 자동으로 여러 줄로 나뉩니다.
5. **저장**: `PNG로 저장`을 누릅니다. 폰에서는 `사진 앱에 저장 / 공유`도 쓸 수 있습니다.

사진은 외부 서버로 보내지지 않고, 누끼까지 모두 브라우저 안에서 처리됩니다.

## 배치 규칙 (구역 고정)

| 구역 | 위치 (y) | 내용 |
|---|---|---|
| 한국어 제목 | 240 – 400 | Pretendard Bold, 최대 130px. 길면 작아지고, 그래도 넘치면 2줄 |
| 영어 / 중국어 | 415 – 575 | 최대 68px. 한 줄 → 안 되면 여러 줄 (중국어는 Noto Sans SC) |
| 사진 | 595 – 1625 | 누끼 딴 돌을 이 구역 안에서 최대 크기로 가운데 배치 |
| 산지 · 규격 | 1621 – 1721 | Pretendard Bold, 최대 60px |

글자는 자기 구역 안에서만 줄어들거나 줄바꿈되므로 사진 영역을 침범하지 않습니다.
`미리보기에 구역 표시`를 켜면 구역 경계를 확인할 수 있습니다(저장 이미지에는 안 나옴).

## 개발

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # docs/ 폴더에 배포용 파일 생성 (AI 모델 포함)
```

- `src/render.js` — 템플릿 배치와 글자 맞춤 규칙 (구역 좌표는 `ZONES`, 글자 크기는 `STYLE`)
- `src/cutout.js` — 자동 누끼, 지우개/복원 브러시
- `src/main.js` — 화면 동작
- `src/assets/template.jpg` — 기본 템플릿

## 사용한 것

- 글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL 1.1), 중국어는 Noto Sans SC (Google Fonts)
- 누끼: [@imgly/background-removal](https://github.com/imgly/background-removal-js) (브라우저 내 AI, AGPL-3.0)
